Halaman visualisasi data sederhana yang menampilkan informasi dalam bentuk diagram batang dan tabel menggunakan HTML. Proyek ini dibuat untuk melatih kemampuan dalam menyusun dan menyajikan data agar lebih mudah dipahami melalui tampilan yang terstruktur. Fokus utama proyek ini adalah penyajian informasi yang jelas, rapi, dan mudah dibaca oleh pengguna.

Fitur:
- Menampilkan data dalam bentuk diagram batang
- Menyajikan data dalam format tabel
- Struktur halaman yang sederhana dan mudah dibaca
- Penyajian informasi yang terorganisir

Tech Stack:
- HTML

Tujuan Proyek:
Melatih kemampuan dalam menyusun dan menyajikan data secara visual menggunakan struktur halaman web yang sederhana.
